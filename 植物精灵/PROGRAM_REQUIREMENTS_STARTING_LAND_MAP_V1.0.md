# 植物精灵程序需求规格：起始之地地图 V1.0

来源：起始之地地图设计图与森林遗迹背景图。`Level01` 为起始之地，承担移动教学、首个杂兵战和通向 BossArena 的入口；Boss 数值与四波战斗规则沿用怪物与 Boss V1.5 规格。

## 1. 地图区域

| 区域 | 设计图位置 | 程序地图职责 |
|---|---|---|
| 起始平台 | 左下 1 | 玩家出生、移动与跳跃教学、根系与小型障碍视觉地标 |
| 上层平台 | 左中 2 | 可通过跳跃抵达；首个蘑菇敌人的视觉驻点与收集物位置 |
| 中层通道 | 中部 3 | 主要横向路径，承接四波杂兵战与上下分支 |
| 高台宝箱 | 右上 4 | 高处遗迹、宝箱和篝火视觉地标，作为后续墙跳/可破坏地板扩展预留区 |
| 下层水域 | 右下 5 | 蓝色浅水池视觉地标，连接右侧 BossArena 传送门路径 |

## 2. 美术资源与图层

1. `starting_land_background.png` 作为相机跟随远景，排序层级低于一切地图碰撞体、角色和 UI；背景只跟随相机 X 轴，不参与碰撞。
2. 环境图块位于 `Resources/PlantSpirit/Environment/StartingLand/`，用于起点根系、上层遗迹、中层拱门、高台圣所、水池边缘和平台表面。
3. 平台图块必须对齐现有 `BoxCollider2D` 顶面；改变美术尺寸时不得改变可行走顶面高度。
4. 图块透明区域保留 alpha，不生成物理碰撞；碰撞继续由关卡对象统一管理。

## 3. 运行时要求

1. `LevelArtDecorator` 在 `Level01` 启动时建立起始之地远景和前景装饰；其它场景继续使用原有遗迹装饰逻辑。
2. 背景必须覆盖 16:9 视口，横向相机移动时不得露出纯色边缘。
3. 起始之地前景依次体现根系起点、上层石墙、中层拱门、高台圣所和水域，且不遮挡玩家、敌人、传送门或 HUD。
4. 水域在本版本作为可见地标和后续下潜系统的锚点；实际下潜、宝箱奖励、可破坏木板与墙跳属于下一轮玩法扩展，不应伪造为已实现交互。

## 4. 验收标准

1. 运行 `Level01` 时可见森林遗迹远景，并随相机平滑横向移动。
2. 地图使用本次导入的起始之地图块，且平台碰撞顶面保持可达。
3. 角色、敌人和 UI 的排序高于远景；远景和装饰不得拦截任何物理或触发器事件。
4. `BossArena` 不使用起始之地背景与图块布局。
