# 植物精灵 GGJ48H 可玩 Demo

在 Unity Hub 使用 Unity 2022.3.62f3 打开 `植物精灵` 项目，从 `Assets/Game/Scenes/MainMenu.unity` 开始运行。正式流程使用 `MainMenu` 和 `Level01` 两个场景，不再支持从任意空场景生成整局内容。

完整流程：主页面开始游戏，穿过教学起点，依次清除三个战斗区，拾取藤蔓触须、毒菌伞和铁甲根，按 `Tab` 或 `G` 随时打开嫁接界面，清场后前往传送门并按 `E` 完成关卡。

控制：A/D 或方向键移动，Space 跳跃，Left Shift 冲刺，鼠标左键或 J 普攻，鼠标右键或 K 技能，Tab/G 打开或关闭嫁接，E 进入传送门，Esc 暂停。

当前已接入项目方提供的 168 张运行时 PNG：主角攻击、藤蔓怪、蘑菇、孢子/命中特效和地下遗迹环境。甲虫、主角移动状态、Portal、嫁接图标和 UI 仍保留程序表现，音频尚未接入。

GGJ48H 主流程只包含三种敌人、三个必掉器官、随时嫁接和清场传送门。融合、Boss、随机房间、污染、进化与永久成长均按最新策划明确延期，不会在本次试玩中显示为不可用功能。
